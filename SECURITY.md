# Security Policy

## Supported versions

Security fixes are provided for the latest published version of Photo Viewer.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue.

Use GitHub's **Report a vulnerability** button on the repository's Security
page to send a private report. Include reproduction steps, affected versions,
and the potential impact when possible.

Reports will be acknowledged as soon as practical. Confirmed issues will be
addressed privately before a coordinated public release and advisory.
