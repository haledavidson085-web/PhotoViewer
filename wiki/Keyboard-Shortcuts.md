# Keyboard shortcuts

| Action | Shortcut |
| --- | --- |
| Open image | `Ctrl+O` |
| Open folder | `Ctrl+Shift+O` |
| Previous / next image | `Left` / `Right` |
| Zoom in / out | `+` / `-` |
| Fit to window | `F` |
| Actual size | `1` |
| Full screen | `F11` |
| Leave full screen | `Esc` |
| Start / stop slideshow | `F5` |
| Rotate left / right | `Ctrl+L` / `Ctrl+R` |

Use the mouse wheel to zoom, drag to pan, and double-click to switch between fit and actual size.
